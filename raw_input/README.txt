Place your downloaded raw .ogg chunk files into this folder:
e.g.
  bot-946751602415521873_12600000.ogg
  946751602415521873_12600000.ogg
  bot-234236035846897664_12600000.ogg

Then double-click "merge_raw.bat" or run:
  npm run merge-raw

The script will automatically detect all chunks in here, align all speakers, mix them together, remove the silence/dead air, and play the resulting MP3!
